# Video Files Directory

This directory should contain the video files for the Athlos Forge website.

## Required Files:

### intro-athlos.mp4
- Format: MP4 (H.264)
- Recommended resolution: 1920x1080 (Full HD) or 1280x720 (HD)
- Duration: 30-60 seconds
- Content: Sports/fitness introduction video showing training, motivation, and brand elements
- Optimized for web: Compressed for fast loading
- File size: Under 50MB recommended

### intro-athlos.webm
- Format: WebM (VP9)
- Same content as MP4 but in WebM format for better browser compatibility
- Smaller file size alternative

## Video Specifications:
- Aspect ratio: 16:9
- Frame rate: 30fps
- Bitrate: 2-5 Mbps for MP4
- Audio: Included with clear narration/music
- Subtitles/captions: Optional but recommended

## Implementation Notes:
- Video is set to preload="metadata" for fast loading
- Controls are enabled for user interaction
- Responsive design with max-height constraints
- Fallback message for unsupported browsers
